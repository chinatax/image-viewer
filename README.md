# 看图 — 本机图片/视频查看器（纯前端，零安装）

浏览器里直接浏览**浏览器所在机器**的文件夹。基于 File System Access API，
所有文件读取都在本地浏览器完成，不需要后端、不经过服务器、无口令。

## 原理

- 点击「选择文件夹」后，浏览器向操作系统请求该文件夹的只读授权；
- 之后所有目录枚举、图片/视频读取都在浏览器本机完成（`File` + `URL.createObjectURL`）；
- 因此**看到的是你当前这台电脑的文件夹**，而不是服务器上的。

## 使用条件（重要）

1. **浏览器**：都能用。`showDirectoryPicker`（File System Access API）只有桌面
   Chrome/Edge 提供，能用上「完整模式」；其余浏览器自动走「兼容模式」（见「已知限制」）。
2. **安全上下文**：页面必须通过 `http://localhost` 或 `https://` 打开，
   否则「选择文件夹」不可用。即：不能直接 `file://` 打开，也不能用 `http://内网IP` 打开。

## 快速开始

```bash
./build.sh                 # 构建出 web/dist 纯静态站点
cd web/dist
python3 -m http.server 8000
# 用 Chrome/Edge 打开 http://localhost:8000
```

任意静态服务器（`npx serve dist`、`npx vite preview`、Nginx 等）托管 `web/dist` 均可；
若要多人零安装使用，把 `web/dist` 一次性部署到任意 **HTTPS** 静态托管即可。

## 界面语言（中文 / English）

默认中文。中英文案集中在 `web/src/i18n.ts` 里各存一份，**构建产物是双语的**，
语言在页面渲染时才二选一——所以不用为英文单独构建一次。

要出英文，用 `server/` 里的 Go 服务托管（它会在返回 index.html 时注入语言标记）：

```bash
./build.sh
rm -rf server/dist && cp -r web/dist server/dist   # server/dist 是 go:embed 的输入
cd server && go build -o imageviewer .
./imageviewer --en        # 加 --en = 英文界面；不加 = 中文
```

纯静态托管（`python3 -m http.server` 之类）没有地方传参数，只能是中文。若要在静态
托管下出英文，往 `index.html` 的 `</head>` 前加一行就行：

```html
<script>window.__KANTU_LANG__="en"</script>
```

前端只认这一个信号：`window.__KANTU_LANG__ === "en"` 用英文，其余（没注入、注入别的值）
一律中文，页面上没有切换入口——语言由启动方决定。

## 功能

- 选择本机任意文件夹，浏览其中的图片/视频，可进入子文件夹（面包屑导航）
- **合并多个文件夹：界面上的入口已下线（2026-09-22 用户要求去掉「＋ 添加文件夹」按钮）**。
  机制本身留着 —— `Browser.tsx` 的 `addFolder`（含重名去重、多根持久化）、`fs.ts` 的
  `MergedDir`/`mergeDirs`/`mergeListings`、顶部的根目录 chips、i18n 的 `top.addFolder` 全部
  未动，恢复只需在工具栏加回一个 `onClick={addFolder}` 的按钮。**别当死代码删掉**：自动恢复
  上次的多个根目录那条路（`loadDirHandles`）还在用它，`root.*` 那几条文案也只有那条路会用。
  当初它是绕开「安卓选不了内部存储根目录」的办法：依次选 DCIM、Pictures、Movies 并成一个
  根目录来浏览（同名子目录递归合并），合并是惰性的，之后新加的文件照样能看到。
- 图片大图查看：缩放（适应 / 1:1）、`←→` 翻页、`Esc` 关闭
- 自动轮播：可调间隔、可暂停、循环
- 视频播放：内嵌 HTML5 播放器，对浏览器解不了的格式自动降级转封装/转码（见下）
- 缩略图：本地生成（无需服务端压缩），存内存 + IndexedDB，二次进入/下次打开秒开。
  持久层记录里带文件的 size/mtime，取用时跟真实文件核验——对不上就重新生成，所以
  同名旧图、另一个盘的同名文件夹都不会串图/留在旧画面上（细节见 `web/src/cache.ts`）
- 视频缩略图：桌面端给视频瓦片自动抽一帧当缩略图（滚动到视口才生成、限量并发、
  结果同样进缓存秒开）。覆盖浏览器原生能解的格式和 mpegts.js 能转封装的
  ts/m2ts/mts/flv；mkv/avi/wmv/mpg 等仍显示 ▶ 占位符，手机端也不生成（省电）。
  抽到黑帧/空白帧会换时间点重试、不落盘（细节见 `web/src/videoThumb.ts`）


## 视频格式支持

浏览器（Chrome/Edge）原生只认 **MP4(H.264/AAC)** 和 **WebM** 两种容器，其余格式靠下面的三级降级自动救回来：

| 格式 | 处理方式 | 说明 |
|---|---|---|
| mp4 / m4v / webm / ogv | 原生 `<video>` | 秒开 |
| ts / m2ts / mts / flv | [mpegts.js](https://github.com/xqq/mpegts.js) 转封装 | 秒级，浏览器硬件解码；HEVC 取决于本机硬解能力 |
| mkv / avi / wmv / mpg / mpeg | ffmpeg.wasm 本地处理 | 首次需下载约 31MB 解码器（之后走浏览器缓存） |

mkv/avi 等会先探测内部编码：

- **编码浏览器能解**（如 H.264）→ 只换外壳（重封装），快且无损，不联网上传；
- **编码解不了**（如 MPEG-2、DivX、WMV）→ 只能真转码，网页里软解很慢，所以只转**前 60 秒**做 480p 预览；
- 文件超过 **~700MB** 会拒绝转换并提示用桌面播放器——解码在浏览器内存里完成，超出会把标签页搞崩。

## 已知限制

- 必须 localhost 或 https（浏览器只在安全上下文里给文件夹/文件授权）。
- 桌面 Chrome/Edge 是「完整模式」（能记住授权，下次打开直接进）；Firefox、Safari、
  iPhone/iPad、大部分安卓浏览器和 App 内置浏览器自动降级为「兼容模式」——一样能按文件夹
  看图，只是每次打开要重选一次；安卓上还受「选不了内部存储根目录」的限制（见下）。
- 每次需「选择文件夹」授权，浏览器关闭后需重新选择。
- 从你选择的文件夹开始浏览（含子目录），不列整盘根。
- **安卓上选不了「内部存储」根目录**：安卓 11 起系统禁止把内部存储根目录、SD 卡根目录、
  `Download` 目录本身授权给任何应用，浏览器选到它们时系统会提示「无法使用此文件夹」。
  这不是网页能绕过的（换浏览器也一样），得选 `DCIM`、`Pictures` 这类子文件夹来看
  —— 因此安卓上一次只能看一个文件夹。桌面 Chrome/Edge 没有这个限制。
- **iPad/iPhone 上只能选照片，不能按文件夹浏览**：iOS 把相机拍的照片、视频放在「照片」
  图库，它不是「文件」App 里的目录，系统没有把它作为普通文件夹开放给网页（任何浏览器都
  一样，iOS 18.4 起能选文件夹了也还是这样）。iOS 18.4 起 webkitdirectory 确实可用，但那个
  选择器只看得到「文件」App，用户拍的照片一张都翻不到，**2026-09-22 iPad 实测：这个按钮
  "没啥作用"**。所以 iOS 上直接判为没有文件夹选择（见 `fallback.ts` 的 `detectCaps`），
  只给「选择照片 / 视频」一个入口 —— 与安卓 <M132、华为/鸿蒙同一原则：不发点了没用的按钮。
  从图库选进来的是平铺列表，因为系统没有提供目录结构；要按文件夹浏览请用电脑。
  **2026-09-22 iPad 实测**：点「选择照片 / 视频」弹的是「照片图库 / 拍照或录像 / 选取文件」
  三选一 —— 后两项意味着「文件」App / iCloud Drive / U 盘里的图片视频仍然够得着（选「选取文件」
  挑进来，同样平铺）。
- heic/heif/avif 等格式能否预览取决于浏览器是否原生支持该图片格式。
- 蓝光原盘（20GB+ 的 m2ts）浏览器里无解，需桌面播放器。
